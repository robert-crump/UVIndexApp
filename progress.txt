## 2026-09-19 — Issue #35: UV Forecast — one pure derivation from raw rows plus a clock value

### Status: COMPLETE (manual main screen / 4x1 / 1x1 same-current-hour test still to be done on device)

### What was implemented
- New `data/model/UVForecastDerivation.kt`: `ForecastSnapshot` (raw rows + metadata + fetchedAt) and pure
  `deriveUVForecast(snapshot, now: LocalDateTime): UVForecast?`. No Android imports, no clock reads.
  Returns null when no rows are for today's date (cache miss).

  `testDebugUnitTest` passes.
